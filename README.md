### Qué hago

- **Producto de punta a punta.** Aplicaciones SSR con Astro y Node que atienden tráfico real a diario, con SQLite/Redis, colas de trabajo, cron y scraping incremental de varias fuentes.
- **Infraestructura y operación.** VPS Linux con PM2 en modo clúster, Cloudflare (CDN, WAF, R2, Tunnel, Workers, D1), builds atómicos sin downtime, backups y CI en GitHub Actions.
- **Seguridad.** CSP estricta con nonces, protección CSRF, rate limiting, reglas WAF contra scanners y scrapers, auditorías periódicas con remediación documentada.
- **Rendimiento, SEO y accesibilidad.** Core Web Vitals, caché en el edge, sitemaps y datos estructurados a escala, WCAG 2.2 AA.
- **IA aplicada.** Integración de LLM (Gemini, Groq, modelos locales) en productos con validación de la salida, no solo prompts.

- Documento las decisiones y los incidentes para que el siguiente no tenga que redescubrirlos.
